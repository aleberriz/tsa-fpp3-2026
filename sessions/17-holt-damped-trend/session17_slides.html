    From SES to Holt

    Session 17 · From SES to Holt

    SES gave us a level. Today we give it a slope.

    Session 16: SESToday: Holt, then damped Holt
    Stateslevel ℓlevel ℓ and slope b
    Forecastflat line at ℓTstraight line ℓT + h·bT; damped: a line that levels off
    Weightsαα and β*; damping adds φ
    Fittingsearch for the smallest training SSEthe same search, with more values to choose

    Australian population has risen every year since 1960. What would a flat SES forecast say about 2027?

    SES has one state, the level, so every forecast from origin T equals the final level. Choosing alpha well changes which level that is, never the shape. Holt adds a second state, the slope, measured in the series' units per period: here, millions of people per year.

    The fitting search is the one from Session 16 on fitting SES. Holt has two more values to choose: the slope weight beta-star and the initial slope b0.
    Holt equations

    Session 17 · Holt's linear trend

    Holt adds a slope to the SES equations.

    SESHolt Forecast ŷt+h|t = ℓt + h·bt Level ℓt = αyt + (1−α)ℓt−1(ℓt−1 + bt−1) Slope bt = β*(ℓt − ℓt−1) + (1−β*)bt−1
    • Forecast: each step ahead adds one more final slope, so the forecast ℓT + h·bT is a straight line.
    • Level: blend the observation with where Holt expected the series to be: the old level plus one slope.
    • Slope: blend the latest change in level with the old slope. The weight β* sets how much the slope reacts.
    Read the colored terms as the whole difference between the two methods. The level equation keeps its SES form, except that the prediction it blends with is now the old level plus one slope. The slope equation is new, and it has the same blend-of-new-and-old shape as the level equation.

    The drift method from Session 8 on benchmark methods also projects a slope, but its slope is the average change over the whole sample. Holt's slope is revised every period, so it can follow a trend that speeds up or slows down.
    SES and Holt in R

    Session 17 · SES and Holt in R

    Fitted to the same data, SES stays flat and Holt continues the rise.

    fit_ses_holt <- aus_economy |>
  model(
    SES  = ETS(Pop ~ error("A") + trend("N") + season("N")),
    Holt = ETS(Pop ~ error("A") + trend("A") + season("N"))
  )
fit_ses_holt |> forecast(h = 10) |> autoplot(aus_economy, level = NULL)
    trend("N") asks ETS() for no trend, which is SES; trend("A") asks for an additive trend, which is Holt. Both keep error("A") and season("N"). Fitting them in one model() call puts them in the same model table, so forecast() and autoplot() handle both at once.

    Prediction intervals are switched off here with level = NULL to keep the two point-forecast paths visible.

    Predict first, then update

    Session 17 · Reading the equations

    Predict first, then correct the level, then turn the slope.

    α sets how far the level moves toward the observation. β* sets where the new slope sits between the old slope and the latest change in level.

    The update runs in a fixed order. Predict from the old states, observe, move the level part of the way toward the observation, then revise the slope using the new level. The level move can be written as a correction: new level = prior prediction + alpha × error.

    The latest change in level is a slope estimate from one period, because the run is one period. The slope update averages it with the old slope, which is why the new slope ray always lies between the two other rays.
    What beta-star does

    Session 17 · Reading the equations

    β* is not the slope: it sets how fast the slope reacts.

    trend("A", alpha = 0.8, beta = 0.8 * 0.3)   # fable fixes a weight given inside trend()

    Training RMSE: 0.082, 0.065 and 0.067. Both extremes fit worse. Free to move both weights, the search chose α ≈ 1 and β* ≈ 0.33.

    Alpha is held at 0.8 in all three fits so that only beta-star changes; fable fixes a weight when you give it a value inside trend(). Its beta argument is alpha × beta-star, hence beta = 0.8 * 0.3 for beta-star 0.3.

    A slope that reacts more is not automatically better or worse. Here the middle value fits the training years best, but a training fit says nothing about later years; Section 7 of the notebook returns to that.
    Holt by hand

    Session 17 · Holt by hand

    One update by hand: predict, then the level, then the slope.

    Previous level ℓt−1 = 80, previous slope bt−1 = 2, observation yt = 86; α = 0.5, β* = 0.3. Commit to the three results before revealing.

    StepFormulaPlug in
    Predictŷt|t−1 = ℓt−1 + bt−180 + 2 = 82
    Update the levelℓt = αyt + (1−α)(ℓt−1 + bt−1)0.5 × 86 + 0.5 × (80 + 2) = 84
    Update the slopebt = β*(ℓt − ℓt−1) + (1−β*)bt−10.3 × (84 − 80) + 0.7 × 2 = 2.6

    Workbook 17_B repeats these three formulas in every row of the population series, with the fitted weights supplied.

    Workbook 17_B repeats this order in every row: the Fitted Value column is the prior prediction, from the previous row's level and slope, then the level, then the slope. The fitted weights and initial states are supplied at the top; filling in the rows applies them, it does not estimate them.

    The population fit has alpha almost equal to one, so its new level almost equals each observation. The weights on this slide are moderate so that both parts of each blend are visible.
    Damped equations

    Session 17 · Damped trend

    Damping shrinks the slope a little more at every step.

    HoltDamped Holt Forecast ŷt+h|t = ℓt + h(φ + φ² + … + φh)·bt Level ℓt = αyt + (1−α)(ℓt−1 + φbt−1) Slope bt = β*(ℓt − ℓt−1) + (1−β*)φbt−1
    • Forecast: instead of h full slopes, add φ of the slope for the first step, φ² for the second, and so on.
    • φ = 1 gives Holt back. The smaller φ, the sooner the forecast levels off. In practice 0.8 ≤ φ ≤ 0.98.
    With phi = 1 every factor is one, the forecast adds h full slopes, and we are back to Holt. With phi below one each step adds less than the one before.

    Damping also enters the updates: whenever the slope is carried one period forward, it is multiplied by phi. In practice phi is rarely below 0.8, where damping is very strong, and rarely above 0.98, where the method is almost undamped. These are also fable's default bounds.
    Damped example

    Session 17 · Damped trend

    Fitted damped Holt estimates φ = 0.98, and the paths part slowly.

    ETS(Pop ~ error("A") + trend("Ad") + season("N"))
    trend("Ad") asks for a damped additive trend and estimates phi with the other parameters. Here phi reaches 0.98, the upper bound, which means the data favor an almost undamped trend and the bound keeps a little damping. An estimate at a bound is a reason to look at the forecasts before changing the bound; the notebook appendix shows how to change it.
    How phi shapes the forecast

    Session 17 · Damped trend

    The smaller φ, the sooner the forecast levels off.

    trend("Ad", phi = 0.9)   # fixes phi instead of estimating it

    The forecast approaches ℓT + φbT / (1 − φ). For φ = 0.8 that is at most 0.8 / 0.2 = 4 final slopes: 24.60 + 4 × 0.388 ≈ 26.15 million. For φ = 0.98 it is 49 slopes, about 42.4 million: the 2047 value, 32.7, is a forecast, not the limit.

    The weights phi + phi2 + ... add up to less and less, and their total approaches phi / (1 − phi): 4 slopes for phi = 0.8, 9 for 0.9, 49 for 0.98. The forecast therefore levels off at the final level plus that many final slopes. The notebook appendix derives the total with the same multiply-and-subtract step used for the SES weights in Session 15.

    The four fits here end with almost the same level and slope, so the differences between their paths come from phi.
    Check: a falling trend

    Session 17 · Damped trend

    Damping flattens both rising and falling forecast paths.

    Hold the final level and slope fixed. For a negative slope and 0 < φ < 1, will the damped forecast be above or below Holt at h = 3? Explain before revealing.

    Above: damping reduces the size of the negative trend contribution. For a positive slope it lowers the path instead.

    Damping shrinks the trend's contribution whatever its sign. Holding the final level and slope fixed, it lowers a rising path and raises a falling one. Separately fitted models can also end with different states, so compare their actual forecasts rather than ordering them by phi alone.
    The three dials

    Session 17 · Damped trend

    Three dials: what small and large values mean.

    DialSmallLarge
    α, levelmoves slowly, averages many past observationsfollows the latest observation; α = 1 is the latest observation
    β*, slopebarely changes: in undamped Holt, an almost fixed straight-line trendchases each latest change: the trend can turn quickly
    φ, dampingslope fades fast: the forecast levels off within a few periodsslope persists: almost Holt’s straight line; φ = 1 is Holt

    Holt fit: α = 1.00, β* = 0.33. Damped fit: α = 1.00, β* = 0.43, φ = 0.98. Both levels track each year; both slopes follow lasting changes in growth, and the damped slope fades only slowly.

    The two endpoints are worth remembering. With alpha = 1 the level is the last observation, as in the naive method. With beta-star = 0 in undamped Holt the slope never moves from its starting value, so the trend is a fixed straight line; with damping, beta-star = 0 still lets the slope decay by phi each period. With phi = 1 there is no damping, which is Holt.

    Large is not better than small, or the reverse. A dial that reacts quickly follows real changes sooner and also chases noise; one that reacts slowly ignores noise and also misses real changes. The training fit picks the settings; held-out errors judge them.
