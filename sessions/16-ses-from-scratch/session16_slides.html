    Session 16 · Fitting SES in R

    Each candidate parameter pair produces its own fitted values.

    A trial changes alpha, the weight on a new observation, or the initial level. Either change affects later level estimates, so the full sequence of updates must run again before comparing its sum of squared errors with another trial.

    The build-then-check pattern also appeared in Session 7 on decomposition, Session 12 on prediction intervals and Session 13 on accuracy measures. Here a function name can be attached to each part of the fitting process.

    The optimizer needs only a parameter vector and a function returning a score. It does not need to know that the score came from a forecasting model. optim() is in R's stats package, loaded at startup.
    Implement and test ses_levels()

    Session 16 · Level and error functions

    Each fitted value uses the preceding level.

    levels: l0, l1, l2, ..., lT observations: y1, y2, y3, ..., yT fitted: l0, l1, l2, ..., l(T-1)
    • For T observations, y1 through yT, the vector stores an initial level l0 and T revised levels. It therefore contains T + 1 entries.
    • The fitted-value vector stops at l(T-1), because lT already uses the final observation yT. That final level forecasts the next period.
    Two rows of labels help keep the index shift straight: vector position 1 holds the initial level at time 0. Allocating numeric(length(y) + 1) before the loop leaves room for that initial estimate and every update.

    The reference vector checks the recurrence with fixed parameters before testing a complete fit. all.equal() tolerates floating-point rounding; a mismatch may come from indexing, inputs or a different parameter value, so inspect the first differing entry.
    Implement the error score

    Session 16 · Level and error functions

    SSE adds the squared errors of the one-step predictions.

    et = yt − ŷt|t−1 SSE = ∑ et2

    At time t, subtract the earlier forecast ŷt|t−1 from the observed value yt to get the residual et. SSE_func() squares those residuals and adds them, so each observation must align with the prediction made before it arrived.

    SSE has squared units: if the observations are percentages of GDP, its terms are squared percentage-point errors. RMSE returns to the original units by averaging those squared errors and taking a square root.

    The notebook tests the objective separately from the optimizer. That separation matters: a search can successfully minimize a function that scores the wrong pairs of observations and predictions.
    Supplied wrapper

    Session 16 · Checking the numerical fit

    The wrapper turns a parameter pair into one SSE value.

    my_ses_sse <- function(par, y) { levels <- ses_levels(y, alpha = par[1], l_0 = par[2]) predictions <- levels[seq_along(y)] SSE_func(y, predictions) }

    Here y contains the observations, while par contains alpha, the smoothing weight, and l_0, the starting level. The supplied wrapper calls your two functions. Its slice keeps one preceding level per observation, then returns the sum of squared errors (SSE) for the optimizer to compare.

    The order inside par is a convention that must stay consistent: here par[1] is alpha and par[2] is the initial level. Starting values and reported estimates follow that same order.

    Holt adds a slope and its smoothing parameter, so its corresponding parameter vector is longer. The idea of mapping a parameter vector to one objective value stays the same.
    Run the numerical search

    Session 16 · Checking the numerical fit

    The search estimates alpha within the SES bounds.

    opt <- optim(c(0.1, y[1]), my_ses_sse, y = y, method = "L-BFGS-B", lower = c(0.0001, -Inf), upper = c(0.9999, Inf))

    The notebook searches alpha and the initial level together. Starts and stopping rules can affect the result; compare the objective and forecasts, and repeat from another start if needed.

    The picture uses illustrative observations 10, 14, 12, 16 and 13, with the initial level fixed at 10. Each point on the curve reruns SES and adds its squared prediction errors. The two paths take four simple downhill steps from different starts, reaching nearby but unequal estimates. They illustrate approximation rather than the exact steps of L-BFGS-B.

    In 16_D: numerical search, both alpha and the initial level are estimated. The bounds keep alpha between 0.0001 and 0.9999; the initial level is unrestricted. Compare convergence, objective, fitted values and forecasts. Convergence reports a stopping condition, not proof of a global minimum.

    Session 16 · Checking the numerical fit

    Convergence reports that the search met its stopping rule.

    opt$convergence opt$value opt$par
    • For the annual Algerian exports dataset, opt$convergence reports the stopping status, opt$value the sum of squared errors (SSE), and opt$par the estimated parameters.
    • Compare the fitted values and forecasts with fable as well as SSE. If they differ materially, try another start with identical data and bounds, because convergence alone does not prove a global minimum.
    Two numerical fits can stop at slightly different parameter values. Before attributing the difference to an algorithm, check that the data, model, objective and parameter bounds really match.

    Compare the size of the discrepancy in fitted values, objective and forecasts. Similar predictions can be more informative than agreement in every parameter digit. A convergence code describes a stopping condition, not proof that no better minimum exists.

    Session 16 · Evaluating forecasts

    A lower training error still needs a forecast test.

    Training SSE, the sum of squared errors, helps fit a model. To judge its usefulness, choose an evaluation horizon and error measure that match the decision, then compare forecasts with later observations excluded from fitting. Residual diagnostics can reveal patterns the model missed.

    The three checks answer different questions. Training SSE chooses parameters for an objective, residual diagnostics look for structure left behind, and later observations test predictions made without their outcomes.

    Session 14 on cross-validation repeats that final check at several forecast origins. The parameters must be fitted again inside each training set; reusing estimates from the full series would import future information.
    Argentina exports dataset: parameter exercise

    Session 16 · Argentina exports dataset

    The fitted alpha determines how much recent exports matter.

    Use the annual dataset of Argentina's exports, measured as a percentage of GDP. Fit ETS(A,N,N), the SES specification with additive errors, no trend and no seasonality.

    • Alpha is the smoothing weight on a new observation. Calculate the weights on the three latest observations, then check them in R.
    • Account for older observations and the initial level when explaining the remaining weight, and consider whether a flat forecast suits this dataset.
    When attaching weights to years, the largest weight belongs to the most recent observation. The notebook's reversal of the time order makes that alignment explicit.

    The remaining weight includes earlier observations and the initial level. Interpreting alpha requires the fitted value and the length of the series; a responsive estimate by itself does not establish that the forecast will work well.

    Session 16 · Argentina exports dataset

    Residual variation determines the first forecast interval.

    Residuals → SSE → estimated variance → interval For the first forecast: point forecast ± 1.96 × sigma

    In the SES exercise on Argentina's annual exports dataset, SSE is the sum of squared residuals. Divide it by T − K, where T counts observations and K counts estimated smoothing parameters and starting states. Its square root estimates sigma. Under normal errors, the first 95% prediction interval extends 1.96 sigma on either side of the point forecast.

    The interval calculation revisits Session 12 on prediction intervals. It uses residual variation to estimate uncertainty around the first forecast, with an allowance for estimated smoothing parameters and starting states.

    A small set of residuals is useful for rehearsing the arithmetic. The actual model's interval should use its complete training fit and assumptions. Longer-horizon intervals need the model's horizon-specific forecast variance.
