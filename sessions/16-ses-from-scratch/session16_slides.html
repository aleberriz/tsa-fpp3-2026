    Read the functions and wrapper

    Session 16 · Read the supplied calculation

    The supplied functions connect parameters to a score.

    ses_levels(y, alpha, l_0) Initial state, then one update per observation.
    SSE_func(y, predictions) Subtract each preceding prediction, square, then add.

    my_ses_sse(par, y) joins them: candidate pair → predictions → SSE. Run the fixed-input checks in the notebook.

    The supplied functions separate the recurrence from the score, then connect them with a wrapper. A search can minimize an incorrectly coded objective successfully. The fixed-input checks help establish that observations are paired with predictions made before those observations arrived.
    Run the grid and numerical search

    Session 16 · Search and interpret

    Choosing the lowest grid score is already fitting.

    The grid fixes the initial level; the bounded optim() call searches both parameters.

    Starting guesses launch the search. They do not fix its estimates.

    SSE is a criterion we chose. For the same additive-normal model, data and constraints, likelihood has the same optima. Session 19 develops this connection.

    The plotted scores use Algeria exports in global_economy, 1960 to 2017, with the initial level fixed at the first observation. The numerical search also varies that initial level. SSE and conditional Gaussian likelihood have the same optima for a matching additive-normal model, observations and parameter constraints; different numerical implementations can still stop at different approximations.
    Compare the fitted outputs

    Session 16 · Search and interpret

    Convergence reports that a stopping rule was met.

    opt$par # estimated alpha and initial level opt$value # training SSE opt$convergence # completion status

    Two runs report convergence = 0, with training SSE 42 and 39. What follows about the fit and future forecasts?

    Both runs report successful completion. On matching data, 39 is the better training score.

    Neither result certifies a global minimum, correct code or forecast accuracy.

    Compare with the library. Check data, model, objective and bounds; inspect predictions and try another start if needed.

    Two numerical fits can stop at slightly different parameter values. Before attributing the difference to an algorithm, check that the data, model, objective and parameter bounds really match.

    Compare the size of the discrepancy in fitted values, objective and forecasts. Similar predictions can be more informative than agreement in every parameter digit. A convergence code describes a stopping condition, not proof that no better minimum exists.

    This evaluation forecasts five successive years from one origin, the end of 2012. No method observes 2013 before forecasting 2014. The grid and library fit use only the training sample. RMSE and MAE pool horizons one to five, in percentage points of GDP. The training-score table omits the first observation for every method to match the available naive residuals. One holdout gives evidence for this window; it does not establish a universal model ranking.

    Session 16 · Retrieve the main ideas

    Explain what each kind of evidence establishes.

    How does fitting choose parameters?Generate predictions and seek a smaller training criterion. SSE is one choice.
    What does successful convergence establish?A stopping condition was met. It certifies neither a global minimum, correct code nor useful forecasts.
    How do we check forecasting claims?Use later observations excluded from fitting, and inspect the training residuals for what the model missed.
    Explain the fitting objective, the numerical stopping status and the predictive check separately. Parameter estimates and a training score describe the fit. Held-out errors assess forecasts at a chosen horizon; residual diagnostics look for structure left in the fitted errors.
    Homework: 16_B parts 1 to 8

    Session 16 · Retrieve the main ideas

    Keep these five ideas when fitting a model.

    1. Choose parameters to reduce a criterion on past data.
    2. The criterion is a choice: SSE here, likelihood in Session 19.

    3. A good training score does not establish forecasting skill.
    4. Convergence reports a stopping rule; it certifies neither a global minimum, correct code nor useful forecasts.

    5. Check held-out forecasts and inspect residuals.
