    Implement and test ses_levels()

    Session 16 · Build two functions

    Store the initial level as well as the updates.

    levels: l0, l1, l2, ..., lT observations: y1, y2, y3, ..., yT fitted: l0, l1, l2, ..., l(T-1)
    • The level vector has T + 1 entries.
    • The final level is the next forecast; it is excluded from the fitted-value vector.
    Implement the error score

    Session 16 · Build two functions

    Score predictions using their residuals.

    et = yt − ŷt|t−1 SSE = ∑ et2

    Write SSE_func(). Check equal vector lengths and confirm that predictions precede observations.

    Supplied wrapper

    Session 16 · Search and verify

    Read the supplied wrapper.

    my_ses_sse <- function(par, y) { levels <- ses_levels(y, alpha = par[1], l_0 = par[2]) predictions <- levels[seq_along(y)] SSE_func(y, predictions) }

    Explain the slice before running it. The optimizer needs one number for each candidate pair.

    Run the numerical search

    Session 16 · Search and verify

    Bounds define the search we intend.

    opt <- optim(c(0.1, y[1]), my_ses_sse, y = y, method = "L-BFGS-B", lower = c(0.0001, -Inf), upper = c(0.9999, Inf))
    • Alpha stays slightly inside zero and one. The initial level is also estimated.
    • The starting values begin the search; they are not the final parameter estimates.

    Session 16 · Search and verify

    Convergence is a check, not a proof.

    opt$convergence opt$value opt$par
    • Check stopping status, SSE, fitted values and forecasts against fable.
    • If results differ materially, try another start with the same objective and bounds.
