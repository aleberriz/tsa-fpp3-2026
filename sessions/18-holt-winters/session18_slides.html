    From Holt to Holt-Winters

    Session 18 · From Holt to Holt-Winters

    Holt gave us a trend. Today we give it a season.

    Session 17: HoltToday: additive Holt-Winters
    Stateslevel ℓ and slope blevel, slope and a seasonal effect s for each season
    Forecaststraight line ℓT + h·bTthat line plus the effect of the target season
    Weightsα and β*α, β* and γ

    Australian holiday trips peak every Q1, the Australian summer. What would Holt’s straight line forecast for next Q1?

    Holt supplies the underlying path, a straight line or, damped, one that levels off. Holt-Winters adds one seasonal state per season, four for quarterly data, and restores the target quarter's effect to each forecast.

    The fitting search is again the one from Session 16 on fitting SES, now with a third weight, gamma, and starting values for a full cycle of seasonal effects.
    Holt-Winters equations

    Session 18 · Additive Holt-Winters

    Holt-Winters adds a seasonal state to the Holt equations.

    HoltAdditive Holt-Winters Forecast ŷT+h|T = ℓT + h·bT + sT+h−m(k+1) Level ℓt = αyt(yt − st−m) + (1−α)(ℓt−1 + bt−1) Slope bt = β*(ℓt − ℓt−1) + (1−β*)bt−1 Season st = γ(yt − ℓt−1 − bt−1) + (1−γ)st−m
    • Forecast: start on Holt’s line, then add the latest effect for the target quarter.
    • Level: take the old seasonal effect out of the observation first, so a Q1 peak does not look like a permanent jump.
    • Season: blend this quarter’s fresh evidence with the effect from one cycle earlier, m = 4 quarters back. The weight γ sets how much it reacts.
    The seasonal period m is the number of observations in one cycle: four quarters in a year, twelve months in a year, or seven days in a week.

    Removing the old seasonal effect before the level update keeps a recurring peak from looking like a permanent increase. The slope update is unchanged: once the level is seasonally adjusted, the slope follows it exactly as in Holt.
    Holt and Holt-Winters in R

    Session 18 · Holt and Holt-Winters in R

    Fitted to the same data, Holt draws a line and Holt-Winters restores the seasons.

    fit_holt_hw <- aus_holidays |>
  model(
    Holt     = ETS(Trips ~ error("A") + trend("A") + season("N")),
    additive = ETS(Trips ~ error("A") + trend("A") + season("A"))
  )
fit_holt_hw |> forecast(h = "3 years") |> autoplot(aus_holidays, level = NULL)
    season("N") asks ETS() for no seasonality, which is Holt; season("A") asks for additive seasonality. Fitting both in one model() call lets forecast() and autoplot() show them together. h = "3 years" gives twelve quarters.

    Holt's line runs through the middle of the swings, so its errors carry the whole seasonal pattern. That is why its training RMSE is more than twice the seasonal model's.

    Predict first, then update

    Session 18 · Reading the equations

    Predict, then update: the season uses the previous level and slope.

    Predict yₜ ŷt|t−1 = ℓt−1 + bt−1 + st−m Update the level remove st−m from yt, then blend with ℓt−1 + bt−1 Update the slope blend ℓt − ℓt−1 with bt−1, as in Holt Update the season blend yt − ℓt−1 − bt−1 with st−m Predict yₜ₊₁ ℓt + bt + st+1−m, then the cycle repeats
    • The slope update uses the updated level. The season update uses the previous level and slope: the values that made the prediction.
    • Each state moves by its weight times the prediction error: level αe, slope αβ*e, season γe.
    Each state moves by its weight times the prediction error: the level by alpha times the error, the slope by alpha × beta-star times the error, the season by gamma times the error.

    The seasonal update uses the previous level and slope because those produced the prediction being corrected. Some texts rewrite the update with a different parameter convention, so equations and parameter definitions must be read together.
    What gamma does

    Session 18 · Reading the equations

    γ is not the seasonal effect: it sets how fast the pattern changes.

    season("A", gamma = 0.1)   # fable fixes a weight given inside season()

    Training RMSE: 0.414, 0.431 and 0.466. A fixed pattern fits these trips best, which is why the search chose γ close to zero.

    Alpha and beta are held at the additive fit's rounded values so that only gamma changes. fable fixes gamma when you give it a value inside season().

    A larger gamma suits a seasonal pattern that really shifts over time, for example when a holiday moves or a market changes. For holiday trips the pattern is stable, so a fixed pattern fits best.
    Matching the forecast quarter

    Session 18 · Reading the equations

    Forecasts reuse the target season's latest index.

    ŷT+h|T = ℓT + hbT + sT+h−m(k+1) k = floor((h−1)/m)

    Here h is the horizon, m the cycle length, and k the completed forecast cycles before the target. Check: the sample ends in Q2; which quarter and stored index do you need at h = 5, m = 4?

    The last m observed seasonal indices form a rolling calendar, even if the series ends halfway through a year. A future January uses the latest observed January index, which need not belong to the last complete calendar year.

    Horizons one full cycle apart reuse the same seasonal index; their trend contributions still differ because more time has elapsed. The notebook appendix has a hand-drawn version of this lookup for monthly data.

    Fixed amounts or proportional swings

    Session 18 · Proportional seasonality

    Proportional seasonality changes the size of the swing.

    • Fixed-size swings suggest an additive effect in the data’s units: subtract it to adjust, add it to forecast.
    • Growing swings suggest a multiplicative factor around one: divide to adjust, multiply to forecast.
    Additive seasonal effects are centered around zero; multiplicative factors are centered around one. This is the same identification idea used in Session 7 on decomposition: the seasonal component should not also carry the overall level.

    A plot suggests which form to try. It does not settle which one forecasts better.
    Multiplicative equations

    Session 18 · Proportional seasonality

    Multiplicative Holt-Winters: divide to adjust, multiply to forecast.

    AdditiveMultiplicative Forecast ŷT+h|T = (ℓT + h·bT) + × sT+h−m(k+1) Level ℓt = α(yt − st−m)(yt / st−m) + (1−α)(ℓt−1 + bt−1) Slope bt = β*(ℓt − ℓt−1) + (1−β*)bt−1 Season st = γ(yt − ℓt−1 − bt−1)(yt / (ℓt−1 + bt−1)) + (1−γ)st−m
    • Q1’s fitted factor of 1.16 puts its forecast 16% above the underlying path; Q3’s 0.93 puts it 7% below.
    • The slope equation and the calendar lookup stay the same; the level and season updates now divide by a factor instead of subtracting an effect.
    The level and slope still combine additively in the multiplicative method; only the seasonal effect changes role. Dividing by a factor removes it from an observation, and multiplying restores it to a forecast.

    The notebook appendix replays the fitted multiplicative model in a reference table, for an optional algebra check. The required workbook uses additive seasonality.

    Seasonal damping

    Session 18 · Proportional seasonality

    Damping flattens the underlying path, not the seasons.

    trend("Ad") damps the underlying path in either seasonal form. The seasonal effects repeat as before; only the level-plus-slope part levels off. The notebook appendix gives the full damped seasonal updates.
    The four dials

    Session 18 · Proportional seasonality

    Four dials: what small and large values mean.

    DialSmallLarge
    α, levelmoves slowly, averages many past observationsfollows the latest seasonally adjusted observation
    β*, slopebarely changes: without damping, an almost fixed straight-line trendchases each latest change: the trend can turn quickly
    γ, seasonbarely changes: nearly the same pattern every year; γ = 0 fixes the indiceseach quarter’s effect is rebuilt mostly from its latest year
    φ, dampingslope fades fast: the underlying path levels off soonslope persists: almost undamped; φ = 1 is no damping

    Holiday trips, additive fit: α = 0.26, β* = 0.165, γ = 0.0001. A moderately responsive level, a slowly turning slope and an almost fixed seasonal pattern.

    Two endpoints are worth remembering. Without damping, beta-star = 0 keeps the slope at its starting value, so the underlying trend is a fixed straight line; with damping the slope still decays by phi. With gamma = 0 the seasonal effects stay exactly at their starting values, like the fixed seasonal indices of classical decomposition in Session 7; the fitted gamma of 0.0001 lets them change very slightly.

    Large is not better than small, or the reverse. A dial that reacts quickly follows real changes sooner and also chases noise; one that reacts slowly ignores noise and also misses real changes. The training fit picks the settings; held-out errors judge them.
    Forecast evidence

    Session 18 · Judge the forecasts

    Forecast errors can challenge the model suggested by a plot.

    A seasonal pattern suggests candidates. Session 16 on fitting SES gives three distinct questions for judging them:

    • Training scores: how closely did the fitted settings reproduce the training observations?
    • Residual diagnostics: what structure did the model miss?
    • Held-out errors: how useful were forecasts on observations excluded from fitting?

    The holiday-trips plots illustrate assumptions. The arrivals homework adds held-out accuracy; narrow intervals alone cannot establish a better forecast.

    A seasonal model needs starting values for its whole cycle as well as the level and slope. More flexibility can improve fit without guaranteeing better forecasts, which motivates the selection criteria in Session 19 on ETS estimation and selection.

    For intervals, check which future observations they cover as well as how wide they are.
